# MAUI Essentials Parity Matrix

This ledger tracks Mirage/browser parity for `Microsoft.Maui.Essentials` APIs. It distinguishes three questions for each feature: whether canonical MAUI static API parity is achievable via DI, whether injected-interface parity is achievable via DI, and what parity is possible without upstream MAUI changes.

Status legend:
- `DI parity`: `no`, `injected-only`
- `without upstream`: `none`, `partial`, `good`
- `upstream change needed`: `yes`, `no` (called out in Notes when it materially changes the parity path)

## Closing Notes
- `MainThread`, `Permissions`, and `Platform` are the hard non-DI blockers.
- File/result-based APIs need special caution because `FileBase`, `FileResult`, and similar result types still rely on platform partials.
- `DeviceInfo.Platform = DevicePlatform.Create("Browser")` is useful even without upstream changes, but it does not fix `OnPlatformExtension`.
