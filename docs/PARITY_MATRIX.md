## Current browser coverage snapshot
- Complete: `Window`, `ContentPage`, `ContentView`, stack/grid/absolute layout mapping, `Button`, `CheckBox`
- Partial: `NavigationPage`, `ScrollView`, `FlexLayout`, `Label`, `Entry`, `Editor`, `SearchBar`, `Switch`, `Slider`, `Picker`, `DatePicker`, `TimePicker`, `Stepper`, `ProgressBar`, `ActivityIndicator`, `Image`, `ImageButton`, `Border`, `Shapes.Ellipse`, `Shapes.Line`, `Shapes.Path`, `Shapes.Polygon`, `Shapes.Polyline`, `Shapes.Rectangle`, `Shapes.RoundRectangle`, `CollectionView`, `IndicatorView`, `RefreshView`
- Missing: `GraphicsView`, `CarouselView`, `SwipeView`, `WebView`
- Shared core substrate: `IView.Clip` (`RectangleGeometry`/`RoundRectangleGeometry`), `IView.Shadow` (solid paint), and `IView.Background` (`SolidPaint` + `LinearGradientPaint`) are implemented in the common browser mapper.
- Styling/presentation proof: showcase pages (`showcase-page-home`, `showcase-page-text-input`, `showcase-page-form-media`, `showcase-page-layout-collection`) now validate MAUI style-system behavior (`implicit`, `explicit`, `BasedOn`, `StyleClass`, `DynamicResource`) on top of parity handlers.
- CollectionView note: Mirage now uses a MAUI-shaped handler chain with deterministic incremental updates and equality-based selection sync on the non-virtualized runtime path; grouped/reorder/full anchoring parity remains documented as partial.
- Label note: Mirage now covers core label mapper parity plus controls text-source projection (`FormattedText`, `TextType`, `TextTransform`) with deterministic safe-subset HTML sanitization; remaining label gaps are limited to HTML breadth and span gesture hit-region parity.
