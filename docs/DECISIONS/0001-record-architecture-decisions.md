# 0001 — Record Architecture Decisions

Date: 2026-03-01

## Status
Accepted

## Context
This repo will evolve quickly. We need a lightweight way to capture decisions so we don't
re-litigate key architectural choices.

## Decision
Use small ADRs under `docs/DECISIONS/` with a numeric prefix.

## Consequences
- Public-facing decisions become easier to reference.
- Breaking changes require an ADR.
