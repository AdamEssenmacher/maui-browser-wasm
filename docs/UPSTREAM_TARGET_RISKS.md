# Upstream MAUI Unofficial-Target Risks

This document tracks upstream MAUI shared-code assumptions that can misbehave when Mirage runs outside MAUI's official target set.

- Audit date: 2026-03-25
- Upstream source: `dotnet/maui` at commit `6717d1cb84a039ca6c3563f28b2df2879ceb0b7e`
- Local truth source: active Mirage only (`src/Mirage.*`, current samples/docs/tests)
- Out of scope for local evidence: legacy `src/Maui.Browser*`
- Separate concern: intentional Mirage behavior gaps live in [PARITY_GAPS.md](PARITY_GAPS.md)
- Feature-by-feature `Microsoft.Maui.Essentials` browser parity status is tracked separately in [ESSENTIALS_PARITY_MATRIX.md](ESSENTIALS_PARITY_MATRIX.md).

## Status legend

- `Covered`: Mirage has an explicit mitigation in the active stack.
- `Partial workaround`: Mirage reduces the risk, but does not fully replace the upstream assumption.
- `Avoided by scope`: Mirage mostly avoids the risky path by staying out of that feature area.
- `No workaround`: no active Mirage mitigation was found in source or docs.
